# Desafío Todo List

Desafío realizado para el módulo de JavaScript de Desafío Latam.

## Descripción

Aplicación web que permite gestionar una lista de tareas utilizando JavaScript y métodos de arreglos.

La aplicación permite:

- Agregar nuevas tareas.
- Eliminar tareas.
- Marcar tareas como realizadas.
- Visualizar el total de tareas.
- Visualizar el total de tareas realizadas.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
